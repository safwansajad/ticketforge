# TicketForge Frontend

React + Vite client for ticket issuance and PNR vouchers.

## Prerequisites
- Node.js 18+
- Backend API URL

## Setup
1) Install deps: npm install
2) Create .env with VITE_API_BASE_URL=http://localhost:5000
3) Run dev server: npm run dev

## Build
- npm run build
- npm run preview   # optional preview of the build

## Lint
- npm run lint

## Notes
- Uses React Router and Axios.
- Update VITE_API_BASE_URL to the deployed backend (Render/other).
